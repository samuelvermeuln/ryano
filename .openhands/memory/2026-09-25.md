## BUG PRÉ-EXISTENTE ENCONTRADO (não corrigido — decisão do usuário)
`app/escola/[schoolId]/convites/invite-links-panel.tsx` monta o link como
`/entrar/convite/${invite.id}`, mas `app/entrar/convite/[token]/page.tsx`
resolve via `ResolveInvitationLink` → `hashInvitationToken(token)` comparado
a `InvitationLink.tokenHash`. O **id nunca é o token**, logo todo link
copiado por essa tela dá 404 "Convite não encontrado".

Pior: o token cru **não é persistido** (só o hash), então para convites já
criados o link é **irrecuperável**. O botão "Copiar link" não é só
quebrado, é infixável para linhas existentes. Correção real = mostrar o
link só no momento da criação (foi o que fiz no fluxo novo de professor,
`inviteCoachAction` devolve `token` de `createInvite.execute`) e
remover/desabilitar o botão na tela de convites.

## Organograma (escola > professores > alunos)

### Decisões de design
- **Suspensão por escola vive em `CoachSchoolMembership.suspendedAt/suspendedBy`**,
  NÃO em `CoachProfile.status` (global — desativaria o professor em todas as
  escolas em que trabalha) e NÃO em `MembershipStatus.ENDED` (significa "saiu da
  escola"; `RemoveCoachFromSchool` encerra todos os vínculos de alunos e cancela
  prescrições futuras).
- Histórico de transferência vem dos próprios períodos de `CoachAthleteAssignment`
  (já temporal: startedAt/endedAt/assignedBy/endedBy). Só faltava `reason`.
  Tabela de auditoria paralela seria segunda fonte de verdade.
- `transitionCoachSchoolMembership` limpa a suspensão ao sair (só linha ACTIVE
  pode carregar os campos) — quebrou 3 testes que asseravam o payload exato do
  `update`; atualizá-los era a correção certa.

### Armadilhas (custaram tempo)
- **`z.infer` vs `z.input`**: campo com `.default()` fica OBRIGATÓRIO no tipo de
  saída. `CreateCoachAthleteAssignmentInput` virou `z.input<...>`, senão 9 call
  sites quebram. Uma mudança de tipo em vez de 9 edições.
- **Campos que NÃO existem** (assumi e quebrou): `UserProfile.birthDate` (não
  existe em lugar nenhum -> "idade" do aluno é impossível sem nova coluna; decidi
  NÃO inventar), `TrainingLicense.startsOn/endsOn` (reais: `startedAt` e
  `expiresAt`), erro `SCHOOL_ATHLETE_MEMBERSHIP_NOT_FOUND` (real: `ATHLETE_NOT_FOUND`).
- **`findLastAccess` retorna `{ at, hasActiveSession }`**, não `lastAccessAt`.
  `at: null` = **desconhecido** (sessões são podadas no logout), NUNCA "nunca
  acessou" — a UI diz "Não disponível".
- **eslint react-hooks é rígido aqui**: proibido `ref.current = x` durante o
  render (mover para effect) e `setState` sincrônico dentro de effect. A correção
  boa para o highlight de drop foi resolver a zona DENTRO do handler de
  pointermove (`zoneAt`) e devolver `over` no estado do drag, eliminando o effect.
- Não há biblioteca de drag-and-drop no projeto; usei Pointer Events com limiar
  de 6px para separar clique (abre gaveta) de arraste (transfere).
